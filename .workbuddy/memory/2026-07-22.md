用户关键决策（后续实现必须遵守）：
- 只使用 music2emo 引擎，彻底删除 librosa 回退路径
- 机器有 RTX 5070（sm_120），用 CUDA 加速；torch 需 cu128+ 版本
- 速度目标：流畅连续更新即可，不追求极限首结果延迟
- OCR 框选：常驻直到下次检测或停止，不跟随窗口移动
- 校准：换/升级模型为主（MERT-v1-95M → 330M），个性化校准层（保序回归，>=10 样本生效）也要

方案要点：
- A1 准确性：引擎内升级 MERT-v1-330M + 新增 core/mood_calibration.py（CalibrationStore + Calibrator）+ 象限图 3x3 校正网格
- B1 速度：stdin 二进制帧（8 字节 header + float32 PCM）替代临时 wav、子进程启动预热、10s 窗 / 2s 步进滑动窗口、EMA alpha 0.35 → 约 0.5、崩溃只自动重启一次
- OCR 框选：删 1500ms 自动关闭，overlay 实例复用 + update_rects 原位更新

风险：torch cu128 安装、330M 与现有回归头兼容性（实现期实验决定）、边界检测阈值需实测微调。

## 实现计划已生成（commit c38ec4a）

`docs/superpowers/plans/2026-07-22-mood-accuracy-speed-ocr-overlay.md`，8 个任务：
1. install.bat/requirements 升级 torch 2.7.1+cu128（RTX 5070 sm_120 必需）
2. server.py v2 重写：全模型常驻预热（MERT+BTC+jsons）+ 全内存推理 + 二进制帧协议 READY v2
3. client v2 重写：struct "<II" header + float32 PCM、warmup()、restart()、_readline_text 兼容 bytes/str
4. analyzer 重构：10s 窗/2s 步进、删 librosa 回退、崩溃重启一次、last_raw_va、set_calibrator；main_window._start_audio 加 warmup
5. core/mood_calibration.py：CalibrationStore(JSON) + Calibrator(sklearn isotonic, MIN_SAMPLES=10)
6. gui/calibration_popover.py 3x3 网格（信号 corrected(valence, arousal)，格子值 ±2/3、0）+ main_window 校正按钮接线
7. OCR overlay 常驻：删 1500ms 定时器、update_rects 复用、停止时销毁
8. verify_330m.py 兼容性验证（预期 2048 != 1536 INCOMPATIBLE → DEAM 重训留作后续独立计划）

关键实现发现：repo 版 predict 每次都重载 BTC 模型 + MERT 特征写 npy + music21 调式分析，是慢的主因；330M hidden=1024 与头部 1536 输入架构上不兼容，直接换模型不可行。
计划自查修了 4 处：client 二进制流与 text=True 冲突、测试 mock readline 循环应答、popover 测试 (v,a) 顺序、overlay 复用需先删开头销毁块。

## Task 8: MERT-v1-330M 兼容性验证结论

`music2emo_engine/verify_330m.py` 实测（torch 2.7.1+cu128，CUDA，m-a-p/MERT-v1-330M）：
330M embedding 维度（layers 5,6 拼接）= **2048**，现有回归头 `FeedforwardModelMTAttnCK` 输入 = **1536**，
exit 1 **INCOMPATIBLE**——与 spec 预判一致，不能用 `M2E_MERT_MODEL` 环境变量直接替换骨干。

DEAM 重训触发条件（满足任一即启动，属后续独立计划）：
- 用户愿意下载 DEAM 数据集并授权重训流程；
- 或情绪准确性实测仍不达标、且校准层（Task 5）无法弥补时。

环境备注（本机）：huggingface.co 可直连但系统代理（127.0.0.1:7897）MITM 导致 venv 内 requests 证书校验失败；

可行组合：`HF_ENDPOINT=https://huggingface.co` + `REQUESTS_CA_BUNDLE` 指向「Windows 根证书 + certifi」合并 PEM；
且须从 PowerShell 启动 python（Git Bash 传环境变量会触发 torch DLL 加载 access violation）。
