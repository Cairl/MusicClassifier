## 问题二：界面 DPI 模糊（已完成并验证）
根因：
- `gui/main_window.py` 用 `setFixedWidth(int(240*dpr))` 手动乘 dpr，与 Qt6 自动 High DPI 缩放叠加，窗口被错误放大但内部字号/padding 没跟，比例失调 + 小字号非整数缩放发虚
- `gui/sidebar.py` 的 `_svg_icon` 用 `QPixmap(size,size)` 创建物理像素位图，没设 `setDevicePixelRatio(dpr)`，高分屏放大后图标边缘糊
- `main.py` 全局字体用繁体 `Microsoft JhengHei`，简体环境不合适

修复（49 测试通过）：
- main_window.py：去掉手动 ×dpr，直接 `setFixedWidth(240)`/`setFixedHeight(360)` 逻辑像素，让 Qt6 自动缩放
- sidebar.py：`_svg_icon` 按屏幕 dpr 创建高分辨率 pixmap 并 `setDevicePixelRatio(dpr)`；`setIconSize` 改用 `QSize(22,22)` 逻辑尺寸
- main.py：字体换 `Microsoft YaHei UI`
- 顺手清掉两处按钮文案的三角符号（用户要求任何地方不用 emoji）

## 问题八：侧边栏按钮图标只显示左上角（已完成）
用户纠正：问题在 sidebar 按钮，不是象限图。图标只露出左上角。

根因：`QSvgRenderer.render(painter)` 不传目标矩形时按 SVG 原始尺寸（256×256）渲染。但 pixmap 物理像素只有 `size*dpr`（如 42×42 @150% DPI）。256px 渲染内容只有左上 42×42 区域落入 pixmap，其余被裁剪——于是只看到图标的左上角。

修复：`renderer.render(painter)` → `renderer.render(painter, QRectF(0, 0, size, size))`，强制 SVG 缩放到 pixmap 的逻辑尺寸。
需要 `from PySide6.QtCore import QRectF` 导入。
59 全绿。

## 问题十：四象限情绪识别不工作（已修复）
根因：ProcessAudioCapture 输出 `WAVE_FORMAT_EXTENSIBLE`（format tag 0xFFFE）WAV，实际编码由 SubFormat GUID 指定（IEEE float = {00000003-...}）。但 `_parse_wav_header` 只认 format tag==3，见到 0xFFFE 直接 return None，header 永远解析失败，buffer 始终为空。

诊断三步：
1. 20s 0 events → pipeline 断了
2. buffer=0 header_parsed=False → 音频未进 buffer
3. 读原始 pipe hex → format=0xFFFE, SubFormat DWORD=3（确是 IEEE float）

修复：`audio_capture.py` 增加 EXTENSIBLE 分支，当 tag==0xFFFE 时读 pos+32 SubFormat GUID 首 4 字节校验 IEEE float。
验证：修复后 1s 内 buffer=98 samples，snapshot (2, 47040) 正常。
59 全绿。

## 问题十一：切歌后四象限不动（已修复）
根因：locked 状态下 `_handle_result` 直接 emit 锁定值并 `return`，跳过了 `_detect_boundary`。同时 locked 后 `_recent_coords` 不断 append 相同的锁定坐标，distance 恒为 0，boundary 永远无法触发。

1. `_detect_boundary` 增加 `result` 参数，locked 时若 quadrant 变化直接视为 boundary（不依赖距离阈值）
2. 调整调用链传入 `result`
3. `tests/test_audio_analyzer.py`：更新 4 处 `_detect_boundary` 调用，增加 `MoodCoordinates` 参数
