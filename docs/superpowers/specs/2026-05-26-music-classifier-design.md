# MusicClassifier 设计文档

## 概述

半自动 Apple Music 歌曲分类工具。在 Windows 上运行，通过 OCR 识别 Apple Music 歌单中的歌曲信息，用户在 PySide6 GUI 中选择分类，程序自动完成点击操作将歌曲添加到目标歌单。

## 技术方案

**OCR + PyAutoGUI** 方案：截图 Apple Music 窗口 → OCR 识别歌名 → 用户选择分类 → 模拟鼠标点击三点菜单和目标歌单。

选择此方案的原因：Apple Music Windows 版是 WebView 渲染的 UWP 应用，UI Automation API 大概率无法获取内部控件元素。OCR 方案虽"笨"但最可靠。

## 架构

```
MusicClassifier/
├── main.py                  # 入口
├── core/
│   ├── screen_capture.py    # 截取 Apple Music 窗口
│   ├── ocr_reader.py        # OCR 识别歌名、行定位
│   ├── action_executor.py   # 模拟鼠标点击（三点菜单、目标歌单）
│   └── playlist_config.py   # 歌单分类配置（卷→情绪→歌单名）
├── gui/
│   └── main_window.py       # PySide6 主界面
└── config.json              # 用户配置（窗口区域、歌单映射等）
```

### 模块职责

- **screen_capture**：定位 Apple Music 窗口，截取歌单列表区域截图
- **ocr_reader**：对截图做 OCR，提取每行的歌名和对应三点按钮的坐标位置
- **action_executor**：根据用户选择的分类，模拟鼠标点击三点菜单 → 添加到歌单 → 选择目标歌单
- **playlist_config**：维护分类体系（风之卷/花之卷/海之卷/月之卷/人之卷 → 四种情绪），供 GUI 下拉选择

## 数据流

### 逐首分类流程

1. **截图阶段**：`screen_capture` 截取 Apple Music 歌单列表区域，输出截图图像
2. **OCR 识别阶段**：`ocr_reader` 识别歌名文本 + 定位每行三点按钮坐标，输出 `List[TrackInfo]`
   - `TrackInfo = { song_name, artist, row_y, dots_btn_pos }`
3. **用户选择阶段**：PySide GUI 显示当前歌曲，用户从下拉框选择分类（卷 → 情绪），点击「分类」按钮
4. **自动操作阶段**：`action_executor` 执行：点击三点按钮 → 等待菜单弹出 → 点击「添加到歌单」→ 等待歌单列表弹出 → 点击目标歌单名 → 等待操作完成
5. **下一首**：回到步骤 1，重新截图，识别第一首未分类歌曲，重复 2-4

### 关键设计决策

- **每首都重新截图**：点击三点菜单后列表可能滚动或刷新，重新截图最可靠
- **三点按钮定位**：OCR 识别歌名后，根据歌名 y 坐标，在同一行最右侧区域通过模板匹配精确定位
- **目标歌单定位**：弹出歌单列表后再次截图 + OCR 识别歌单名，找到目标歌单坐标后点击

### 交互逻辑

- **卷下拉框**选择后，**情绪下拉框**联动更新（选月之卷 → 情绪选项变为满月/弦月/残月/新月等）
- **分类此首**：执行点击操作，完成后自动重新截图进入下一首
- **跳过**：不操作，直接重新截图进入下一首
- **重新截图**：不跳过也不分类，重新截取当前状态
- **操作日志**：实时显示每步操作结果
- **进度条**：显示已处理/总数

## 错误处理

| 场景 | 检测方式 | 应对策略 |
|------|---------|---------|
| Apple Music 窗口未找到 | pygetwindow 查找窗口标题失败 | GUI 提示"请先打开 Apple Music"，禁用操作按钮 |
| OCR 识别失败/歌名为空 | OCR 结果为空或置信度低于阈值 | GUI 提示"识别失败"，提供「重新截图」按钮 |
| 三点按钮定位失败 | 模板匹配得分低于阈值 | GUI 提示"无法定位三点按钮"，允许用户手动点击后继续 |
| 菜单未弹出 | 点击后截图对比无变化 | 重试点击一次，仍失败则跳过并记录日志 |
| 目标歌单在列表中未找到 | OCR 歌单列表中无匹配项 | 提示"歌单未找到"，可能需要滚动歌单列表 |
| 操作中途窗口被遮挡/最小化 | 截图后检测窗口状态 | 暂停操作，提示用户恢复窗口后继续 |
| 歌曲已在目标歌单中 | Apple Music 会弹出提示 | 检测弹窗，关闭后标记为"已存在"并跳过 |

### 操作间隔与稳定性

- 每次鼠标点击后等待 500ms-1000ms（可配置），确保 UI 响应
- 截图前等待 300ms，避免动画未完成
- 所有点击操作在独立线程执行，不阻塞 GUI

## 依赖

- Python 3.10+
- PySide6：GUI 框架
- PaddleOCR：中英文 OCR 识别
- pyautogui：鼠标键盘模拟
- pygetwindow：窗口定位
- opencv-python：模板匹配、图像处理
- Pillow：截图处理
